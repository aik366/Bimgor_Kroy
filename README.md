# Bimgor_Kroy — расчёт расхода ПВХ-плёнки для мебельных фасадов

Программа на Python для расчёта погонных метров ПВХ-плёнки и построения
схем раскладки фасадов на полотне с учётом технологических зазоров,
краевых отступов, текстуры плёнки и размеров рабочего стола.

## Возможности

- Загрузка размеров из файла заказов `22.txt` по номеру заказа
  (`№|длина|ширина|количество|...`), разворот позиций по количеству.
- Вопрос о типе плёнки: **с текстурой** (поворот на 90° запрещён) или
  **без текстуры** (поворот разрешён).
- Эвристика 2D-упаковки Bottom-Left Fill + перебор 6 стратегий сортировки.
- Автоматическая разбивка заказа на несколько столов (отрезов ≤ 3000 мм),
  отдельный PNG-файл схемы на каждый стол.
- На схеме: номер позиции заказа одним цветом для всех штук позиции,
  размеры, координаты, зоны зазоров и краевых отступов.
- Независимая проверка зазоров, границ и стола.

## Установка

```bash
pip install -r requirements.txt   # нужен только matplotlib
```

## Запуск

```bash
python run.py                      # спросит номер заказа и тип плёнки
python run.py --order 0002 --no-texture
python run.py --order 0005 --texture
python run.py --demo               # встроенные тесты без файла заказов
python run.py --help               # все опции
```

## Файл заказов `22.txt` (не входит в репозиторий)

Кодировка cp1251, заказы разделены строкой `#@#`:

```
#@#
0002|Ткаченко|12.01.2026|...
I - 16 Ст-т|...
1|960|411|2||16|15/БФ|Фасад||481|0.79|0.79|
2|200|797|2||16|15/БФ|Фасад||481|0.32|0.32|
```

Положите свой `22.txt` рядом с `run.py`.

## Параметры по умолчанию (меняются в начале `run.py`)

- Рулон плёнки: 1200 мм; стол: 3000 × 1200 мм
- Технологический зазор между деталями: 50 мм
- Краевой отступ от краёв стола: 50 мм
